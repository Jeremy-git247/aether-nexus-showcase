# Screenshot placeholders

No screenshots are bundled. These slots prevent an incomplete or sensitive capture from being mistaken for a finished public demo.

| Suggested filename | Intended view | Current status |
| --- | --- | --- |
| mission-control.png | Dashboard with synthetic mission titles and progress | Awaiting safe capture |
| artifact-review.png | Prepared demo artifacts and review controls | Awaiting safe capture |
| recovery-state.png | A demonstration pause or failure state | Awaiting safe capture |

Capture only an isolated demonstration environment. Exclude connection settings, keys, tokens, webhooks, real account/channel/place identifiers, browser profiles, personal paths, real prompts, and sensitive generated content. Inspect the entire image before adding it, including tabs, notifications, and background windows.

After review, add the image to this directory and link it from the main README using a relative path. Do not use a screenshot from a live account simply because credentials appear masked.
